### IndieGoWeb Ltd

IndieGoWeb Ltd is a UK-based software company specializing in B2B automation services and SaaS products. We build n8n-based workflows, agentic systems, and AI integrations for small businesses.

**Technology:**
- **Automation:** n8n-based workflows and agentic systems
- **Stack:** Next.js, Vercel, Supabase, Postgres
- **AI Integrations:** Gemini, Claude, ElevenLabs, Composio

**Open Source Contributions:**
All of our open source work (custom n8n nodes, utilities, MCP servers, and infrastructure boilerplates) is published and maintained under the [whybothercoding](https://github.com/whybothercoding) GitHub account.

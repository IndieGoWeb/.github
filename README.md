# .github

This repository holds the organization-level profile and default community-health files for the [IndieGoWeb](https://github.com/IndieGoWeb) GitHub organization.

## Organization Profile

The organization's public profile is generated from `profile/README.md`. 

IndieGoWeb Ltd focuses on B2B automation services and proprietary SaaS products. Our open source development is primarily published under the [whybothercoding](https://github.com/whybothercoding) GitHub account.

## Community Health Fallbacks

This repository will also store the default community-health files that apply to any `IndieGoWeb` repository that doesn't define its own. GitHub automatically falls back to these files when a repo is missing its own copy.

See [GitHub's docs on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization) for how the fallback works.
